# Code review: hardfacts v0.1 (matt-code-review, two axes)

Fixed point: empty tree → `HEAD` at the end of ticket 10 plus the audit fixes. Two independent sub-agents reviewed it, and each finding was re-probed through `check()`. Fixes landed in the commit that follows this file. Each is locked in `tests/test_review_regressions.py`.

## Standards

No hard violations: tests go through the public seam with literal expectations, and the core is stdlib-only.

| Finding | Kind | Resolution |
|---|---|---|
| Upper-case money magnitudes dropped (`$2.1B` → `$2.1`) | bug | fixed: magnitude suffixes and words are case-insensitive |
| `5c coin` read as 5 °C (bare `C`/`F` matched case-insensitively) | bug | fixed: an attached scale letter must be upper-case |
| `第二十五` yields Claim `十五` (the `第` lookbehind only guards the first char) | bug | fixed: no numeral may start inside another numeral |
| Email Evidence can never support a URL Claim (dead branch) | bug | fixed: a domain Claim is supported by an email at that domain |
| `cjk_number` never returns None, so its None guards are dead | dead code | removed |
| `(previous in _TENS and w in _TENS)` is subsumed | dead code | removed |
| `_Span` imitates `re.Match` for one caller | speculative | replaced by plain offsets |
| `_exempt` repeats 7 identical loops | duplication | table-driven |
| Kind list is repeated in check, feedback and cli | shotgun surgery | one Kind registry (`_kinds.py`) |
| `kind == "exempt"` blurs the glossary (an Exempt span is not a Hard fact) | naming | kept internal; documented as a marker, never reported |
| Value shape varies by Kind (`Any`) | primitive obsession | accepted: the shapes are the public JSON contract, documented per Kind in the README |
