hardfacts

Every number, date, amount, phone number and ID in an LLM's answer, checked against what the model was actually given. Values with no source get struck out. It's deterministic, takes milliseconds and makes no model calls.

Built with Claude Code in one autonomous session, 26 September 2026. The demo below runs the real library in your browser.

FaithBench, never tuned on, showed the same 96% fabrication recall; its first score exposed a tokenisation bug, and the README reports that score as it came out. τ-bench is real GPT-4o and Claude runs as retail and airline agents, pre-registered, with 240 flags blind-audited.

Honest limits

What it can't do

  • Binding. The right value on the wrong subject passes. It catches 22% of source values moved to the wrong place, almost all through a Kind mismatch.
  • Correct arithmetic. A computed total is still flagged, because no source states it. It shows the working ("$6.32 = $101.12 − $94.80") but can't tell right operands from wrong ones.
  • Prose claims aren't hard facts. Use it in front of an LLM judge, not instead of one.
  • The BM and 中文 rules have not yet had a full native-speaker review.
Get it

Install

  1. pip install "git+https://github.com/seekerPrice/hardfacts"
  2. PyPI and npm packages come when the repository reaches 100 stars.
  3. Read docs/writeup.md and the ADRs, then run tools/verify.sh.
