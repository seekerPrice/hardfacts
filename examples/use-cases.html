Five places a bot can quietly invent a number

hardfacts reads a draft reply, pulls out every hard fact (amounts, dates, IDs, tracking numbers, counts, percentages) and looks for each one in the data the model was given. It uses no second LLM and gives the same answer every time, in a few milliseconds. Every result below is real output from the library, including the two it gets wrong.

✓ found in the source ✗ no source states it = arithmetic, shown for review

Order-status replies on WhatsApp

E-commerce support bot
Draft reply

Hi Aina! Your order ORD-2024-0012 ships via Pos Laju. Tracking: EN123456780MY, arriving 2 October. Shipping was RM 12.90.

What the model was given (order API)
{"order_id": "ORD-2024-0012",
 "tracking": "EN123456789MY",
 "eta": "2026-10-03",
 "shipping_fee": 12.9}
✓identifierORD-2024-0012
✗identifierEN123456780MYone digit off: a parcel that doesn't exist
✗date2 Octoberthe record says 3 October
✓moneyRM 12.90matched by value against 12.9
Then
Block the send. Pass feedback(report) back to the model for a second draft, or route the message to a human.

Refunds and fare differences

Airline or retail agent with tools
Draft reply

Your new fare is $101.12 and you paid $94.80, so the difference of $6.32 will be charged to your card ending in 1784.

Tool results
{"new_fare": 101.12,
 "paid": 94.8,
 "payment_method_id": "credit_card_9921784"}
✓money$101.12
✓money$94.80
✗money$6.32 = $101.12 − $94.80not in any source, but the working is shown: check two operands, not the whole reply
✓identifierending in 1784matches the end of credit_card_9921784
Then
Allow it when report.unexplained is empty (only arithmetic was flagged), or send it for review. On real support-agent runs, about 1 in 10 of these computed values was wrong, so the working is worth a glance.

Answers from an internal policy (RAG)

HR, insurance or compliance assistant
Draft answer

Full-time staff get 16 days of annual leave, and unused leave expires on 31 March 2027. Claims above RM 500 need HR approval.

Retrieved passage
Annual leave: full-time employees are
entitled to 14 days per year. Unused
leave may be carried forward until
31 March 2027. Expense claims above
RM 500 require approval from HR.
✗quantity16the policy says 14
✓date31 March 2027
✓moneyRM 500
Then
Retry, or show the answer with the wrong figure highlighted. It won't catch "expires" vs "carried forward": a wrong word with no number in it is outside what this library checks.

A coding agent's "all done" summary

Claude Code Stop hook
Agent's final message

Done: PR #3337 is merged, all 251 tests pass, and the build finished in 42 s.

What the session's tools printed
$ gh pr view 3337 --json state
{"state": "MERGED"}
$ pytest -q
249 passed, 2 failed in 4.21s
$ npm run build
Built in 41.8s
✓identifier#3337
✗quantity251the test run said 249 passed, 2 failed
✗quantity42false alarm: 41.8 rounded. Rounding is flagged on purpose (a looser rule let too many inventions through)
Then
The hook warns before you trust the summary. Measured on real sessions, it would have fired on 16% of turns, which is why it warns by default instead of blocking.

Creator shortlists for a KOL campaign

Influencer-matching agent
Draft recommendation

Top pick: @makan.with.mei, 128K followers, 4.2% engagement, quoting RM 3,500 per Reel. Her last campaign drove 1,240 sign-ups.

Creator record
{"followers": 128000,
 "engagement_rate": 0.042,
 "rate_card": {"reel": 3500},
 "past_campaigns": [{"signups": 1204}]}
✓quantity128Kmatched against 128000
✗percent4.2%false alarm: the record stores the rate as a fraction (0.042). Store percentages as percentages, or expect this flag
✓moneyRM 3,500
✗quantity1,240transposed digits: the record says 1,204
Then
Send the flags to the account manager before the shortlist reaches a brand. A client quoting a wrong performance number back is the expensive version of this bug.

Where it doesn't help: hallucinations with no specific value in them (a wrong policy rule, a made-up reason), sources that are themselves wrong, and wording it has no rule for yet. On the held-out support-agent test it caught 98.2% of planted fabrications, and 19.7% of its flags were its own mistakes before the fixes that audit led to. Python and TypeScript give identical results: from hardfacts import check or import { check } from "hardfacts".
